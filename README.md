# 🚗 CarHub
 
CarHub is a Salesforce-based application developed using Lightning Web Components (LWC) to manage car inventory, view vehicle details, and provide advanced search and filtering capabilities. The application delivers a responsive and interactive user experience while leveraging Salesforce's native platform features.
 
## Features
 
- View and manage car listings
- Display detailed information for each vehicle
- Search and filter cars dynamically
- Responsive user interface using Salesforce Lightning Design System (SLDS)
- Seamless integration between LWC and Apex
- Interactive and reusable Lightning Web Components
 
## Technologies Used
 
- Salesforce Platform
- Lightning Web Components (LWC)
- Apex
- SOQL
- Salesforce Lightning Design System (SLDS)
- HTML
- CSS
- JavaScript
 
## Project Architecture
 
- **LWC Components** for user interface and interactivity
- **Apex Controllers** for business logic and data operations
- **SOQL** for data retrieval
- **SLDS** for consistent Salesforce-native styling
 
## Key Functionalities
 
### Car Listings
Displays available cars with relevant information such as:
- Model
- Brand
- Price
- Year
- Availability Status
 
### Car Details
Provides detailed information about a selected vehicle.
 
### Search & Filters
Allows users to:
- Search vehicles by name
- Filter records dynamically
- Quickly locate desired cars
